# Security Policy

## Reporting

Please report vulnerabilities privately through GitHub's security advisory flow. Do not open a public issue containing exploit details or sensitive data.

## Supported version

The latest commit on `main` is supported.

## Deployment notes

The included workspace contains synthetic demonstration data. Before using Morrow with real organizational evidence, add authentication, tenant-scoped authorization, evidence provenance signatures, data retention controls, and environment-specific encryption policies.
